# Check-List Marvel

Une page web interactive (fichier HTML unique, sans dépendance externe) permettant de cocher au fur et à mesure les films et séries du MCU, dans un ordre de visionnage recommandé — de Iron Man jusqu'à Secret Wars.

![style](https://img.shields.io/badge/style-comic%20halftone-e8262c) ![format](https://img.shields.io/badge/format-HTML%20autonome-f2b632)

## Fonctionnalités

- Cases à cocher pour chaque film, série et saison
- Ordre de visionnage chronologique recommandé, organisé par phase
- Note IMDb affichée pour chaque film/saison (à venir = pas encore noté)
- Encadré "Prochain à regarder" mis à jour automatiquement selon la progression
- Barre de progression globale
- Sauvegarde automatique de l'état coché
- Bouton de réinitialisation du registre
